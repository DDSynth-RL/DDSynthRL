# DDSynth-RL

Official implementation of **DDSynth-RL: Audio Synthesizer Inversion via Discrete Diffusion with Reinforcement Learning**, accepted at **ISMIR 2026**.

[[Paper]](https://arxiv.org/abs/2608.03032) | [[Demo Page]](https://ddsynth-rl.github.io/DDSynthRL-Demo/)

## Overview

DDSynth-RL is a research codebase for audio synthesizer inversion with discrete diffusion and reinforcement learning.

The repository contains training and evaluation code for autoregressive, discrete diffusion, flow matching, and GRPO-based models.

The codebase is currently being organized for public release. The README and usage documentation will be updated accordingly.
