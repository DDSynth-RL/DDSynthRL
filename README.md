# DDSynth-RL

DDSynth-RL is a research codebase for audio synthesizer inversion with discrete diffusion and reinforcement learning.

You can find a demo page for this work at: https://tristan-wu-musicai.github.io/DDSynthRL-Demo/

The repository currently contains training and evaluation code for autoregressive, discrete diffusion, flow matching, and GRPO-based models.

This project is a work in progress. The README and usage documentation will be rewritten later.
